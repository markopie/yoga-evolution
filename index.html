Install on iPhone

  1. Install Tailscale from the App Store and sign in with the approved user’s own account.
  2. Allow the VPN configuration and confirm the iPhone appears under Machines.
  3. Open the canonical HTTPS Yoga address in Safari, then use Share → Add to Home Screen.

PC Ethernet and phone Wi-Fi are compatible when both devices show connected in Tailscale.

Troubleshooting

If the machine is missing, check the selected tailnet and enable the Tailscale VPN. For an authstate2 cookie error, close the stale browser page and restart sign-in from the Tailscale app.
